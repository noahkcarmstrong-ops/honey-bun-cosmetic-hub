# Honey Bun Cosmetic Hub

A small cosmetic foundation for Roblox experiences, styled to match the Honey Bun Hub interface.

## Load

Run this in your executor:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/noahkcarmstrong-ops/honey-bun-cosmetic-hub/main/loader.lua", false))()
```

## Current features

- **Cosmetics** tab for the cosmetic foundation
- **Right Shift** toggles the interface
- **Refresh** checks the latest loader version

No hats or visual effects have been added yet. Future cosmetics are intended to be client-side effects.

## Status

This is an early foundation for the Honey Bun Cosmetic Hub. Cosmetic options will be added over time.
